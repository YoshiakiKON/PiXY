PiXY 操作マニュアル（日本語）

表紙情報

  • ソフト名: PiXY — Pixel to stage-XY Coordinate Converter
  • 著者: Yoshiaki KON
  • リポジトリ: https://github.com/YoshiakiKON/PiXY
  • Zenodo DOI: 10.5281/zenodo.18174474
  • ライセンス: MIT
  • 最終更新: 2026-07-30（v1.4.3仕様）

概要

  • 目的: 顕微鏡画像上の候補点（重心）と装置上の参照点を結び付け、画像座標を装置ステージ座標へ変換することで、装置稼働時間の短縮と再現性向上を支援する。
  • 対象: 微小域分析オペレータ、試料解析担当者、装置管理者
  • 主な機能: 画像読み込み、粒子検出（K-means + 連結成分）、参照点入力、アフィン変換推定、残差可視化、CSV/クリップボード出力
  • 効果: ターゲッティング作業の前倒し、装置上での手作業削減、より多数点の統計的解析が可能に

導入（インストール・起動）

  • 動作環境
    • OS: Windows 推奨（配布 EXE あり）。Linux/Mac はソース実行で動作する可能性あり。
    • Python: 3.8 以上（ソース実行時）
    • 必要ディスク/メモリ: 画像解像度に依存（大画像は多メモリ推奨）
  • 依存パッケージ: requirements.txt を参照（PySide6, OpenCV, NumPy 等）
  • インストール（ソース）
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python Main.py
  • 配布 EXE の実行: ダウンロード後、右クリック→[プロパティ]→[ブロック解除]（必要なら）を行い実行
  • 注意: Python 実行時は仮想環境を有効にし、requirements.txt のバージョンに合わせてください。

クイックスタート（最短手順）

  1. PiXY_ver143.exe を実行
  2. New Project をクリックし、解析対象の画像ファイルを選択して読み込む。
  3. START Centroid Extraction を押す。
  4. 抽出モードで左側パラメータ（Number of Groups, Boundary Offset, Neck Separation, Shape Complexity, Grain Size Threshold ヒストグラム）を調整し，粒子の重心が検出されているか確認．
  5. （推奨）各 Add GroupN ボタンの下にある入力欄へ、手動グループ名を入力する。
  6. 左カードの Add GroupN ボタンで各グループの点を中カラムへ追加する。
  7. Number of Groups を変更して再計算した場合、手動グループ名は色が近いグループへ自動引継ぎされる。複数名が同一グループに衝突した場合は、元グループの点数が多い方を優先する。
  8. Finish Centroid Extraction を押して On-line Alignment に戻る。
  9. Add Fiducial Point をクリックして参照点（画像上）を選択し、装置上で同じ点のステージ座標をテーブルに入力する。3点以上入力し，残差を確認．残差が全体的に大きい場合には点数を増やす．特に大きい点がある場合には，その点を確認もしくは除外する．
  10. 問題なければ Export XYZ または Clipboard で座標を出力して装置へ渡す。

UI 概観

  • 主要ボタン
    • 左側上段（プロジェクト操作）
      • New Project: 新規プロジェクトを開始し、画像ファイルを選択して読み込む。
      • Load Project: 保存済みの .pixy プロジェクト（画像・パラメータ・結果）を読み込む。
      • Save Project: 現在の状態を .pixy プロジェクトとして保存する。
    • 左側中段（参照点操作）
      • Add Fiducial Point: 参照点登録モードに入り、画像上の参照点をクリックしてテーブルへ追加する。
      • Update XY: 選択中の参照点行のステージ座標（Stage X, Stage Y, Stage Z）を更新する。
      • Clear（参照点側）: 参照点テーブルの選択行を削除、または入力をクリアする。
    • 左側下段（粒子検出パラメータ設定）
      • START Centroid Extraction / Finish Centroid Extraction: 抽出モードの開始/終了。
      • 粒子検出パラメータは Advanced 固定で運用。
      • Recalculation Trigger（Auto / Manual）: 粒子検出の再計算方法を切り替える。Auto はパラメータ変更のたびに再計算し、Manual は ReCalculate をクリックしたときのみ再計算する。
      • Number of Groups (K) — K-means のクラスタ数。推奨 3–10（色数に応じて試し、過分割を避ける）
      • Boundary Offset — 画像周縁の不完全領域の影響を避けるためのオフセット（端部の除外など）
      • Neck Separation — 接触粒子を分割する強さ（大きいほど分割が強い）
      • Shape Complexity — 形状が複雑な領域を抑制/分割するための調整パラメータ
      • Grain Size Threshold — ヒストグラムで最小/最大面積を選択
      • グループカード（左下）
        • Add GroupN: グループNの検出点を中カラムへ追加
        • Group name 入力欄（各 Add GroupN の下）: グループの表示名を手動設定
        • Show / Hide: グループごとの表示切替
        • Add ALL Group to List: 全グループを中カラムへ追加
        • Number of Groups またはポスタライズレベル変更時は、グループ表示の個別設定（Show/Hide）を解除し、全グループ表示へリセット
        • Number of Groups 変更後に再計算したとき、手動グループ名は近似色グループへ引継ぎ。衝突時は元グループの点数が多い方を優先
    • 中央（候補点テーブル）
      • Export XYZ: 推定した変換で候補点をステージ座標（X,Y,Z）へ変換し、CSVとして保存する。
      • Clipboard: 出力データをクリップボードへコピーし、装置ソフトへ貼り付けできる形式（TSV）で提供する。
      • Add Target: 画像上でターゲット点を手動追加する（自動抽出以外の点を追加したい場合に使用）。
      • Update u, v: 選択中の行（ターゲット）の画像座標 u, v を、現在クリックしている位置で更新する。
      • Clear（ターゲット側）: ターゲット側の選択状態や一時的な指定をクリアする。
      ※注（Add Target / Update u, v とグループ表示切替の挙動）
      • Update u, v（Update Target）は現状ベータ仕様です。今後のバージョンで内部挙動やUIが変わる可能性があります。
      • Add Target で追加される点は「手動点」として扱われ、グループは常に Group 0 になります。
      • 手動点は候補リストの先頭（No.1）ではなく、「自動抽出された Group 0 の点の末尾」に追加されます。
        • そのため、手動点を追加すると候補点の No.（列番号）が変わることがあります（他の点がずれる）。
      • Update u, v は「選択している点の種類」によって動作が異なります。
        • 選択中が手動点（= Group 0）の場合: その手動点の座標を更新します（点の数は増えません）。
        • 選択中が自動抽出点（Group >= 1 等）の場合: 「置換（replace）」として扱い、
          1. 元の点は候補から非表示（除外）にし、(2) 新しい手動点（Group 0）を追加します。
      • グループの Show / Hide で Group 0 を非表示にしている場合でも、Group 0 以外の点を Update u, v で置換したときに追加される新しい点は 「いま更新した点」として見える状態（表示扱い）になります。
        • これは「更新したのに点が消えて行方不明になる」ことを防ぐための例外的な表示ルールです。
    • 右側（画像表示・見え方の調整）
      • Export Image: 現在のオーバーレイ（境界・重心番号など）を元画像に合成し、画像として書き出す。
      • Original / Posterized と Boundary（Show / Hide）は Centroid Extraction モード中のみ表示。
        • 通常モードは Original + Boundary OFF に固定。
      • Coordinate（Image / Stage）: 表示座標系を画像座標/ステージ座標表示に切り替える。
        • Image座標（u, v）表示時
          • Flip（Normal / Flip）: 画像の左右反転を切り替え、装置表示との左右差を補正する。
          • Image Rotate スライダー: 画像を手動回転し、参照点の再同定を補助する（角度表示と連動）。
        • Stage座標（X, Y, Z）表示時
          • Right（+X / -X）: 分析装置座標の水平方向設定．画面右が正なら+Xを選択
          • Top（+Y / -Y）: 分析装置座標の垂直方向設定．画面上が正なら+Yを選択
  • 画像の操作説明
    • 左クリックドラッグ: 画像の水平移動
    • 画像上でセンターホイール回転: 画像の拡大縮小
  • 表の列説明
    • u, v: 画像座標（ピクセル）
    • Stage X, Stage Y, Stage Z: 装置の座標（装置ごとの単位に従う）
    • Res. X/Y/Z: 各参照点の残差

    • トグルスイッチ: 各点の表示・非表示切替．非表示の点は計算・出力から除外される

ワークフロー詳細

  • Image（候補点生成）
    • 画像を読み込み、Number of Groups (K) でクラスタ数を指定し、K-means により色分割を実行
    • 連結成分解析で領域ごとの重心を計算し、候補点リストを生成
    • パラメータ変更時に自動または手動で再計算（Auto / Manual モード）
  • Fiducial（参照点）入力
    • Add Fiducial Point で画像上の再同定可能な特徴点をクリックして登録
    • 装置側で同点を見つけて Stage X/Y/Z を入力
    • 参照点は非共線の 4 点以上を推奨（5 点以上で安定）
  • Transform（変換推定）
    • 参照点ペアから 2D→3D のアフィン変換を最小二乗で推定
    • 左右反転モデルも試行し、残差が小さいモデルを採用
    • 各参照点の残差を確認し、外れ値は再同定または除外して再推定
  • Export（出力）
    • 候補点を推定変換でステージ座標に変換して Export XYZ / Clipboard で出力
    • 装置固有のインポート形式がある場合は、CSV の列順を確認して調整

機能別ガイド

  • 粒子検出（K-means + 連結成分）
    • 目的: 画像から対象領域（粒子など）を抽出し、各領域の重心（候補点）を得る
    • 主要パラメータ
      • Number of Groups (K) — K-means のクラスタ数。推奨 3–10（色数に応じて試し、過分割を避ける）
      • Grain Size Threshold — 最小領域面積（px）。推奨 10–50 px（ノイズ除去）
      • Maximum Area — 最大領域面積（px）。大きすぎる領域を除外
      • Boundary Offset — 画像周縁の不完全領域の影響を避けるためのオフセット（端部の除外など）
      • Neck Separation — 接触粒子を分割する強さ（大きいほど分割が強い）
      • Shape Complexity — 形状が複雑な領域を抑制/分割するための調整パラメータ（既定値: 3）
    • 調整のコツ
      • まず K と Grain Size Threshold を合わせ、次に接触粒子が多い場合のみ Neck Separation 等で調整する．Advancedのパラメータを調整する際には，計算が重くなるので手動計算推奨．
  • 重心抽出フィルター適用順（現行仕様）
    1. 二値マスクに trim（Boundary Offset）を適用
    2. 連結成分ラベリング
    3. 最小面積未満を早期除外
    4. 残りに neck separation 分割を適用
    5. 分割後コンポーネントに対し最小/最大面積を再適用
    6. Shape Complexity フィルターを適用
    7. 採用コンポーネントについて重心計算と境界オーバーレイを生成
  • 残差可視化
    • GUI の残差テーブルとヒストグラムで分布を確認
    • RMS または中央値＋MAD ベースの閾で外れ値を判定
  • プロジェクトの再現性
    • .pixy にパラメータと結果を保存
    • 現行バージョンでは K-means の内部シードは固定（ユーザー設定不可）

ファイルとフォーマット

  • centroids_*.csv — 出力 CSV（No, Group, Stage X, Stage Y, Stage Z）
  • 入力画像形式: PNG/JPG/BMP 等

  1. 例: 光学像（BSE）を読み込み、K=5, Min area=20px で候補点抽出

付録：数式とアルゴリズム詳細

この付録では、論文本文から省略した主要な数式と、GUI の主要機能で用いるアルゴリズムのロジックをできるだけ詳しく記載します。

K-means によるポスタライズ（クラスタ分割）

  • 目的関数（最小化対象） $$J = \sum_{k=1}^{K} \sum_{x\in S_k} \|x - \mu_k\|^2$$ ここで x は画素の色ベクトル（例: RGB）、Sk はクラスタ k に割り当てられた画素集合、μk はクラスタ k の中心（重心）です。

  • 反復手順（一般的な Lloyd のアルゴリズム）

    1. 初期中心 {μk} を設定（当実装では内部 RNG を固定して初期化）。
    2. 割当てステップ: 各画素 x を最も近い中心 μk に割り当てる（ユークリッド距離）。 assign(x) = arg mink∥x − μk∥2
    3. 更新ステップ: 各クラスタの中心を平均で更新する。 $$\mu_k \leftarrow \frac{1}{|S_k|}\sum_{x\in S_k} x$$
    4. 収束条件: 割当てが変わらないか、中心の移動量が閾値以下、または最大反復回数到達で終了。

  • 実装上の注意

    • 初期化は再現性のため固定シード（cv2.setRNGSeed(12345) 等）を使用することがある（現行バージョンでは固定）。
    • 画像全体での K の選択は経験則に依存するため、GUI で Number of Groups (K) をユーザが調整します。
    • ポスタライズはクラスタラベルを代表色で置換することで可視化します（代表色は各クラスタの平均色など）。

連結成分解析と重心計算

  • 手順
    1. 二値化（ポスタライズ結果から対象クラスタを選択）
    2. ラベリング（4-近傍または8-近傍）で連結成分を抽出
    3. 各成分について面積（ピクセル数）、周囲長、モーメントを計算
    4. 重心 (u, v) は一次モーメントから算出 $$u = \frac{M_{10}}{M_{00}},\quad v = \frac{M_{01}}{M_{00}}$$ ここで Mpq = ∑xpyq は領域のモーメント、M00 は面積です。

サイズフィルター（面積による除外）

  • ロジック
    • 各ラベル領域の面積 A を計測し、閾値以下（min_area）または閾値以上（max_area）の領域を除外します。
  • 疑似コード
for region in labeled_regions:
    A = region.area
    if A < min_area or (max_area is not None and A > max_area):
        discard region
    else:
        keep region

ネックセパレーション（接触領域の分割）

  • 目的: 接触している粒子群を個々の粒子に分離する。
  • よく使われる手法（実装での選択肢）
    1. 距離変換 + マーカーベースのウォーターシェッド
      • 領域の距離変換を計算し、局所極大点をマーカーとして抽出
      • マーカーを初期ラベルとしてウォーターシェッドを適用し、接触領域を分割
    2. 凸包や形状指標に基づく分割
      • 凸包からの逸脱（ソリディティ低下）や円形性の低さを検出し、分割候補とする
    3. 縮小/膨張（モルフォロジー）で細いネック部分を検出し、そこで分割する
  • 実装上のパラメータ
    • Neck Separation の強さ（小さな値は弱い分割、値を上げるほど aggressive に分割）

境界オフセット（Boundary Offset）

  • 画面端やトリミング領域での不完全な粒子を除外するために、画像の周囲を所定ピクセル分トリミングして処理対象外にします。

形状複雑度（Shape Complexity / Compactness）

  • 評価指標例
    • 周囲長 P と面積 A から円形度（circularity）を計算 $$C = \frac{4\pi A}{P^2}$$ 値が 1 に近いほど円形（単純）で、小さいほど複雑（切れ込みや細長）を示す。
    • ソリディティ（領域面積 / 凸包面積）も複雑度指標として有用

座標変換（2D 画像座標 → 3D ステージ座標）の推定

  • モデル（アフィン近似） 画像座標 (u, v) から装置ステージ座標 (X, Y, Z) へのアフィン写像は次のように表せます $$ \begin{bmatrix} X\\ Y\\ Z \end{bmatrix} = \begin{bmatrix} a_0 & a_1 & a_2\\ b_0 & b_1 & b_2\\ c_0 & c_1 & c_2 \end{bmatrix} \begin{bmatrix} 1\\ u\\ v \end{bmatrix} $$ ここでパラメータ行列の各列は定数項と u, v に係る係数を含みます。

  • 最小二乗解の導出

    • 参照点 i が N 個あり、それぞれ画像座標 (ui, vi) と測定ステージ座標 (Xi, Yi, Zi) を持つとする。
    • 行列 A ∈ ℝN × 3 を Ai = [1 ui vi]（各行）とし、B ∈ ℝN × 3 を Bi = [Xi Yi Zi] とすると、各出力座標ごとに線形回帰を行うことでパラメータ行列 P ∈ ℝ3 × 3 を求める。 正規方程式で解くと P = (ATA)−1ATB

  • 残差と評価指標

    • 残差行列 R = B − AP を計算し、各点の残差ベクトルのノルム ∥ri∥ を求める。
    • RMS（root mean square）や各軸ごとの RMS で全体の精度を評価する。

用語集（五十音順）

以下は本マニュアルで使用する主要用語の簡潔な定義です。五十音順にグループ化して列挙します。

【ア行】 - アフィン変換: 画像座標に対する線形変換＋平行移動のモデル。2D→3D の近似として本アプリで用いられる。

【カ行】 - K-means（ケー・ミーンズ）: 画像の色空間を K 個のクラスタに分割する代表的な非階層的クラスタリング手法。 - クラスタ / グループ: K-means によってまとめられた画素集合。

【サ行】 - 参照点（fiducial）: 画像上で再同定可能な特徴点で、装置側で計測したステージ座標と対をなす点。 - 残差（residual）: 推定された変換で予測した座標と測定座標との差。精度評価に用いる。

【タ行】 - トリミング / Boundary Offset: 画像周辺を所定ピクセルだけ処理対象から外す操作。

【ナ行】 - ネックセパレーション: 接触粒子の間にある細い領域（ネック）を検出し、粒子を分離するアルゴリズム。 - ノイズ: 小さな偽領域や誤検出。min_area によるサイズフィルターで除去する。

【ハ行】 - ポスタライズ（Posterize）: 画素をクラスタ代表色に置換して簡潔に表示する処理。 - 形状複雑度（Shape Complexity）: 周囲長と面積などから計算される形状指標（例: circularity, solidity）。

【マ行】 - 面積（Area）: ラベリングされた領域のピクセル数。サイズフィルタリングに使用。 - 重心（Centroid）: 領域の一次モーメントから算出される代表点（画像座標 u, v）。

【ラ行】 - 連結成分（Connected Component）: 二値化画像における連続する画素集合。ラベリングで識別される。

【ワ行】 - ワークフロー: ImageMode（候補点抽出）→ StageMode（参照点入力・変換推定）→ Export（出力）という本ソフトの基本手順。
