バージョン情報（v1.5.2）

v1.5.1 からの主な変更: - UI パラメータ名の統一: 「Grain Size Threshold」→「Particle Size Range (pix)」に明確化 - Boundary Offset、Neck Separation、Shape Complexity を一括制御する「統合制御モード」を追加（個別調整モードとの切り替え可能） - 設定ファイルベースのパラメータ管理（pixy_settings.ini）

v1.5.1 からのアップグレーダーへの注記: - データフォーマットの変更はなし。既存の .pixy ファイルは v1.5.2 でも読み込み可能です。 - UI の用語表現が統一されましたが、機能に変化はありません。

概要

  • 目的: 顕微鏡画像上の候補点（重心）と装置上の参照点を結び付け、画像座標を装置ステージ座標へ変換することで、装置稼働時間の短縮と再現性向上を支援する。
  • 対象: 微小域分析オペレータ、試料解析担当者、装置管理者
  • 主な機能: 画像読み込み、粒子検出（K-means + 連結成分）、参照点入力、アフィン変換推定、残差可視化、CSV/クリップボード出力
  • 効果: ターゲッティング作業の前倒し、装置上での手作業削減、より多数点の統計的解析が可能に

導入（インストール・起動）

  • 動作環境
    • OS: Windows 推奨（配布 EXE あり）。Linux/Mac はソース実行で動作する可能性あり。
    • Python: 3.8 以上（ソース実行時）
    • 必要ディスク/メモリ: 画像解像度に依存（大画像は多メモリ推奨）
  • 依存パッケージ: requirements.txt を参照（PySide6, OpenCV, NumPy 等）
  • インストール（ソース）
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python Main.py
  • 配布 EXE の実行: ダウンロード後、右クリック→[プロパティ]→[ブロック解除]（必要なら）を行い実行
  • 注意: Python 実行時は仮想環境を有効にし、requirements.txt のバージョンに合わせてください。

クイックスタート（最短手順）

  1. PiXY_ver152.exe を実行 ← バージョン番号更新
  2. New Project をクリックし、解析対象の画像ファイルを選択して読み込む。
  3. START Centroid Extraction を押す。
  4. 抽出モード内で、左側検出パラメータ（Number of Groups、Boundary Offset、Neck Separation、Shape Complexity、Particle Size Range ヒストグラム）を調整し、重心が正しく検出されることを確認する。
  5. （推奨）各 Add GroupN ボタンの下のテキスト欄に、グループ名を手入力する。
  6. 左側カードの各グループから Add GroupN ボタンで候補点を追加し、中央のリストに表示させる。
  7. Number of Groups を変更して再計算した場合、手入力したグループ名は最も近い色のグループに自動転送される。複数の名前が1つのグループにマップした場合、ポイント数が多い元のグループが優先される。
  8. Finish Centroid Extraction をクリックしてオンライン位置合わせモードに戻る。
  9. Add Fiducial Point をクリックし、画像上の参照点をクリックして、テーブルに対応するステージ座標を入力する。3点以上登録し、残差を確認する。全体的に残差が大きい場合、点を追加する。1つの点だけ残差が大きい場合、その点を再確認するか除外する。
  10. 問題がなければ、Export XYZ またはクリップボード機能で座標をエクスポートし、装置に渡す。

UI 概要

  • メインボタン
    • 左上（プロジェクト操作）
      • New Project: 新規プロジェクトを作成し、解析対象の画像ファイルを選択
      • Load Project: 保存した .pixy プロジェクト（画像、パラメータ、結果）を読み込む
      • Save Project: 現在の状態を .pixy ファイルで保存
    • 中央左（参照点操作）
      • Add Fiducial Point: 参照点登録モードに入り、画像上の参照点をクリックしてテーブルに追加
      • Update XY: 選択した参照点行のステージ座標（Stage X/Y/Z）を更新
      • Clear（参照点）: テーブルの選択行を削除するか値をクリア
    • 左下（粒子検出パラメータ設定）
      • START Centroid Extraction / Finish Centroid Extraction: 抽出モードの開始・終了
      • 検出パラメータの操作は Advanced モードのみ
      • Recalculation Trigger（Auto / Manual）: 粒子検出の再計算タイミングを制御。Auto は毎回、Manual は ReCalculate クリック時のみ。
      • 統合制御モード（v1.5.2新機能）: チェックボックスで以下を切り替え:
        • 統合制御 ON: 単一の「Aggressiveness」スライダー（0-10）で3つのパラメータをスケーリング
        • 統合制御 OFF: 各パラメータを個別調整（微調整モード）
      • Number of Groups (K) — K-means クラスタ数。推奨 3-10（色の数に応じて試す；過分割を避ける）
      • Boundary Offset — 画像境界近くの不完全領域を除外するオフセット
      • Neck Separation — 隣接粒子の分離強度（大きい = より強く分離）
      • Shape Complexity — 複雑形状領域の抑制/分割パラメータ
      • Particle Size Range (pix) — ヒストグラムベースの最小/最大面積選択（「Grain Size Threshold」から改名）← 改名
      • グループカード（左下）
        • Add GroupN: グループ N の検出点を中央リストに追加
        • Group name 入力欄（各 Add GroupN の下）: そのグループに手入力の表示名を割り当て
        • Show / Hide: グループ単位の表示/非表示切り替え
        • Add ALL Group to List: 全グループを中央リストに一括追加
        • Number of Groups や濃淡レベル変更時、カスタムグループ表示（Show/Hide）がリセットされ全グループが表示される
        • Number of Groups 変更で重心が再計算された場合、手入力名は最も近い色のグループに継承；複数の名前が1つのグループにマップした場合、ポイント数が多い元のグループが優先
    • 中央（候補点テーブル）
      • Export XYZ: 候補点を推定変換式でステージ座標（X,Y,Z）に変換し CSV で保存
      • Clipboard: 出力をクリップボードにタブ区切り形式（TSV）で複写；装置ソフトに直貼り可能
      • Add Target: 画像上に手動で対象点を追加（自動検出されなかった点を追加したい場合）
      • Update u, v: 選択対象点行の画像座標（u, v）を、現在のクリック位置に更新
      • Clear（対象点）: 対象点選択をクリアするか、一時的な指定をリセット
      注記（Add Target / Update u, v とグループ表示）
      • Update u, v（対象点更新）は現在ベータ機能です。内部動作と UI は将来のバージョンで変更される可能性があります。
      • Add Target で追加された点は手動対象点として扱われ、常に Group 0 に属します。

パラメータチューニングガイド

重心検出パラメータ（クイックリファレンス）

パラメータ 一般的な範囲 推奨デフォルト 効果
Number of Groups (K) 2–20 4–5 高い値 = より多くの色グループを分割；過分割に注意
Boundary Offset 0–10 px 0–2 画像端を除外；不完全領域を防ぐ
Neck Separation 0–10 0–5 高い値 = より強く隣接粒子を分離；処理時間増加
Shape Complexity 0–10 3–5 高い値 = 細かい詳細を保持；低い値 = 輪郭を平滑化
Particle Size Range (pix) 10–5000 px 20–100 px 小ノイズ（最小値以下）と大きなアーティファクト（最大値以上）をフィルタ。← 改名

チューニング手順

  1. 最初に K と Particle Size Range を調整（上記推奨範囲参照）
  2. 目的の粒子が検出され、不要なノイズが除去されていることを確認
  3. 隣接粒子が多く残る場合のみ、Neck Separation 等を調整（Advanced パラメータは処理遅延の原因になり得る）
  4. 手動再計算が必要な場合、Manual トリガーモードを使用してラグを回避

統合制御モード（v1.5.2新機能）

  • 「統合制御」をチェックすると、単一の「Aggressiveness」スライダー（0-10）が有効に
  • Boundary Offset、Neck Separation、Shape Complexity を一括スケーリング
  • 急速なパラメータスイープに便利；微調整は個別モードに切り替えて実施
  • プリセット値は pixy_settings.ini で定義され、カスタマイズ可能

参照点登録（オンラインモード）

  • Add Fiducial Point をクリックして参照点登録モードに入る
  • 画像上の各参照点マーカーをクリック
  • 各参照点に対し、対応するステージ座標（X, Y, Z）をテーブルに入力
  • 最低3つ（非一直線上の3点が必須）の参照点を登録
  • 残差を確認（予測位置と観測位置の差分）:
    • 全体的に小さければ、変換は良好
    • 1つの点だけ他より大きければ、その参照点を再確認するか除外
  • 変換を確認後、Export XYZ で対象点座標をエクスポート

トラブルシューティング

重心が検出されない、またはノイズが多い

  1. Particle Size Range を確認・調整 — ノイズを除去し、粒子を保持する範囲を設定
  2. 背景と粒子が混在している場合、K を増やして色グループをさらに分割
  3. 画像品質を確認（コントラスト、シャープネス）— PiXY は高コントラスト画像で最良の結果が得られる

重心は検出されるが断片化している

  1. Neck Separation を増やして隣接粒子を分離
  2. 粒子が複雑な形状の場合、Shape Complexity を増やして詳細を保持
  3. Boundary Offset を確認 — 端が部分領域を切っていないか確認

参照点登録後に大きな残差が生じている

  1. ステージ座標を再確認 — 入力誤りは一般的な原因
  2. 参照点を追加（最低3-5点推奨）— より堅牢な推定のため
  3. 画像品質とズームを確認 — 参照点が明確に見える状態か確認
  4. 残差が特に大きな参照点は除外を検討

ファイル形式

プロジェクトファイル（.pixy）

.pixy ファイルは JSON ベースのプロジェクトアーカイブで以下を含む: - 画像データ（Base64 エンコード） - 検出された対象重心とメタデータ - 参照点とそのステージ座標 - パラメータ設定（ズーム、回転、検出パラメータ） - 抽出モード（Basic / Advanced）

エクスポート形式（CSV）

Export XYZ で出力されるタブ区切り CSV の列構成:

Target_ID  Pixel_X  Pixel_Y  Stage_X  Stage_Y  Stage_Z

設定ファイル（pixy_settings.ini）

v1.5.2新規追加

pixy_settings.ini で以下をカスタマイズ可能: - Aggressiveness プリセット（統合制御モード）: 各レベル 0-10 が特定の Boundary Offset、Neck Separation、Shape Complexity の組み合わせにマップ - UI デフォルト: デフォルト Aggressiveness レベル、統合制御の有効/無効

例:

[Aggressiveness]
preset_0  = 0, 0, 3
preset_1  = 1, 0, 3
...
preset_5  = 5, 3, 5
...

[UI]
default_aggressiveness = 5
unified_control_default = True

このファイルを編集して PiXY を再起動すれば、変更が反映される。

応用トピック

バッチ処理

PiXY は対話的な画像解析用に設計されており、バッチ処理には向いていません。複数画像の抽出が必要な場合: 1. 画像ファイルリストを準備 2. 各画像に対し GUI で対話的に実行、または CalcCentroid.py などの基盤モジュールを使用したカスタム Python スクリプトを作成

カスタム色空間

現在 PiXY は RGB 色空間をデフォルトで使用。HSV、Lab 等の色空間対応は将来版で追加される予定。

オンラインモード位置合わせアルゴリズム

PiXY はアフィン変換（2D 回転、スケール、並進、オプションで Z 平面方程式）を推定し、画像座標（u, v）をステージ座標（X, Y, Z）にマップします。推定は残差の最小二乗最小化を使用。

ヒント・コツ

  • キーボードショートカット: Ctrl キーを押しながらスクロールホイールで画像をズーン/アウト
  • 高速コピー: Clipboard ボタンでタブ区切り座標をコピー；スプレッドシートや装置ソフトに直接貼付可
  • グループ命名: グループに意味のある名前（例：「マトリックス」「介在物」）を付けると、ドキュメント作成が容易
  • プロジェクト保存: こまめに保存 .pixy ファイルには全ての作業とパラメータが保持される
