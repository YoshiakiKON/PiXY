# スクリーンショット撮影と配置ガイド / Screenshot Guide

このファイルは、クイックマニュアルに使用するスクリーンショットの取得方法と命名規則を説明します。

推奨手順:
1. アプリを起動し、目的の画面を表示する。
2. Windows の場合: `Win+Shift+S` で領域選択して保存、または `PrintScreen` を使ってペイント等に貼り付けて切り出す。
3. 画面解像度は 1280x720 以上を推奨。UI が重ならないようツールバーやダイアログを閉じる。

命名規則 (Quick Manual 用):
- 日本語版: `quick_jp_1.png`, `quick_jp_2.png`, ...
- 英語版: `quick_en_1.png`, `quick_en_2.png`, ...

配置先:
- `documentation/images/` にファイルを入れてください。

小さな注意点:
- 可能ならウィンドウ枠を含めず、アプリのコンテンツ領域のみをキャプチャしてください。
- 個人情報やファイルパスが写り込まないよう確認してください。
