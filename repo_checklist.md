Repository checklist for SoftwareX submission

- Include `README.md` with: purpose, installation, usage, example commands, citation (Zenodo DOI).
- Include `LICENSE.txt` (recognized OSI license, e.g., MIT).
- Ensure source code under `src/` or top-level with clear module layout.
- Provide `requirements.txt` or `pyproject.toml` with exact dependency versions.
- Add an example input image and example command to reproduce a simple workflow.
- Tag release matching the manuscript version and archive to Zenodo (record DOI).
- Provide `CHANGELOG.md` with release notes for the submitted version.
- Add `docs/` or `documentation/` linking to detailed parameter descriptions and validation details (use as Supplementary).
- Add a short `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md` if collaborative.
- Ensure `README.md` documents reproduction steps for the validation reported in the manuscript.
