# PiXY — Pixel to stage-XY Coordinate Converter

PiXY is an open-source desktop GUI that maps pixel coordinates from microscope images to instrument stage coordinates, enabling offline preparation of micrometer-scale targets. The repository and archived release include example images and a graphical abstract.

## Summary
PiXY integrates centroid extraction, fiducial-based affine registration, and instrument-ready coordinate export to accelerate targeting workflows for in-situ microanalysis.
